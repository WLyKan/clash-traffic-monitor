# Spec Delta

## Purpose

提供中文桌面趋势、应用与目标下钻、设置和连续后台采集，使从实际 Windows 入口启动的最终包具有与已有功能一致的可验证行为。

## ADDED Requirements

### Requirement: 趋势与下钻
系统 SHALL 提供24小时、7天、30天、本周和本月；日期到小时与应用下钻及键盘行为保持。

#### Scenario: 全列悬停
- **WHEN** 鼠标停在空柱、零柱或极短柱所在列并保持静止刷新
- **THEN** 提示完整日期/时段及上下行合计、质量，边缘避让且移出/切换清除

### Requirement: 排行与设置
系统 SHALL 支持应用选择后的整日、小时、五分钟目标排行，按合计降序，设置提醒与自启并保留已有开关。

#### Scenario: 筛选更新
- **WHEN** 快速切换日期、小时、应用和五分钟
- **THEN** 仅最新响应显示，筛选和选中项保持合理且错误可见

### Requirement: 桌面发行
系统 SHALL 关闭窗口隐藏继续采集，托盘退出才停止并完成事务，最终包无需Python并由真实入口验收。

#### Scenario: 打包和安装
- **WHEN** 从已提交版本打包并更新真实开始菜单
- **THEN** 实际进程路径/哈希和数据物理路径正确，旧历史可查且新增流量递增
